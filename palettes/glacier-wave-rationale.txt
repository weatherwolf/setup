0. HOW CUSTOM THEMES RESOLVE (verified against claude 2.1.220 binary)
-------------------------------------------------------------------------------

  - Claude Code scans ~/.claude/themes/*.json on startup.
  - The SLUG is the FILENAME, not the "name" field inside the file.
      glacier_wave.json  ->  slug "glacier_wave"  ->  "theme": "custom:glacier_wave"
    The "name" field is only the display label in the /theme picker.
  - "base" picks which built-in palette to start from ("dark" or "light").
    Keys you do NOT list in "overrides" inherit that base. A partial file is
    legal and usually looks better than overriding everything.
  - The themes directory is file-watched (chokidar, 300ms debounce), so edits
    to the JSON hot-reload while Claude Code is running. Changing the setting
    in settings.json still needs a restart or a /theme re-pick.
  - /theme also has a built-in editor with a live per-key color picker. It
    writes to this same directory, but it slugifies the NAME when creating
    files ("Blue Shark" -> blue-shark.json), which is how the earlier
    name/filename mismatch appeared.

     these numbers where the wallpaper is light. Treat 4.5:1 here as a floor,
     not a target. This is the same caveat you wrote into wezterm.lua.
